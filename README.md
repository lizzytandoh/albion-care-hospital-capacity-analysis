# Albion Care Hospital Capacity Analysis

## Project Overview
This Power BI project analyses hospital capacity and operational pressures across admissions, bed occupancy, delayed discharges and flu surge scenarios.

## Objectives
- Analyse hospital admissions and capacity trends.
- Monitor bed occupancy and identify capacity pressures.
- Assess the impact of delayed discharges on bed availability.
- Explore the effect of flu surge scenarios on hospital capacity.
- Present key findings through interactive Power BI dashboards.

## Tools Used
- Power BI
- Power Query
- DAX
- Data modelling
- Data visualisation

## Dashboard Pages

### Delayed Discharge Analysis

### Flu Surge Analysis
Explores how increased flu-related demand could affect hospital capacity and operational pressure.

## Data
Admission, staffing and bed management data are stored in separate systems and brought together for analysis in Power BI.
